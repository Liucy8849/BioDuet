# Current research requirements

This records product/research requirements, not an implementation schedule. Earlier detailed plans and the former 60-item checklist are historical material, not a mandatory continuation workflow.

- Two formal comparisons: common-environment Agent capability and complete native-system performance. Report model and harness/configuration differences separately; do not interpret them automatically as mechanism causality. Internal mechanism studies are excluded from the current implementation scope.
- Preserve native Agent reasoning, memory and tool use. Reference runners and adapters must not supply scientific decisions.
- Autonomous analysis means actual code generation/revision, execution, visible errors and produced artifacts. Merely returning an action to a prewritten R analysis does not establish that capability.
- Files, terminals, Python/R, real search and browser interaction are enabled according to task needs. A fixed answer is not live search; an HTTP fetch is not a browser interaction. Missing real service access must be identified rather than silently substituted.
- Two information situations: notified change and evidence-bearing analytical anomaly. Repeated unmotivated record checking is not an objective. Include anomaly-with-correct-label and insufficient-evidence controls; a single marker is not sufficient proof of mislabeling.
- H is role-isolated and independently acts. H0/H1 conditions must not provide different hidden help to different systems. Agent and H permissions are real business constraints, not promises in text.
- Logical-time alternating action can support dual control. Real concurrency is a separate extension, with controlled timing and natural overlap reported separately. It requires actual relevant request overlap, send/receive/commit/reply times and causal evidence. Serial logs or overlapping model calls alone do not qualify. Unsupported concurrency does not reduce logical-time leaderboard performance.
- simulated_replay means explicitly scripted engineering regression; it does not enter the Agent leaderboard.
- Evaluate task completion, scientific evidence and permissions separately. Protocol-format diagnostics do not replace scientific quality. Missing evidence is not a pass.
- The 24 cards remain research scope information. Previously prioritized development cards were 01/04/14 and concurrency cards 17/18/19/21/24; this does not assign their implementation order in the new discussion.
- Earlier expert feedback covered a specific October 21 method packet, reported as approved on October 22. It was not blanket approval of arbitrary new methods or a completed formal evaluation.
- Earlier model testing used deepseek-flash, recorded as DeepSeek-V4.1-Flash-1017. An alias is not immutable model weights. Previous absence of a call/turn ceiling is not a requirement to waste resources; current emphasis is minimal cost. New experimental size and budgets are not yet restated.

Engineering policy: no fallback, fast fail; small maintainable implementations of actual needs, no silent repairs, speculative defensive layers, per-step approval chains or repeated hashing as a default workflow. Necessary application permissions and honest scientific evaluation remain part of the requested functionality.
