# 事件、模拟实验员与可解性

## 三种时序

`replay` 用预置逻辑时钟和屏障检查幂等、乱序、撤权、晚到输出等工程性质，标 `simulated_replay`；`interactive` 冻结外生分布和人侧策略后让 H 根据**自身可见**状态主动行动，保留因 Agent 不同行为产生的不同轨迹；真人赛道须另行授权，标真实人行动而不混进模拟榜。每步记录逻辑时间、发送/接收/提交时间、来源、因果父事件、对象前后版本、身份、读快照、幂等键、回执、费用与所有人主动时间。模拟设备回执不冒充实际仪器测量。

## 人侧策略

用户已确定人侧采用规则约束加受限 LLM：规则层锁定可见对象、grant、实际能力、事件和失误条件；受限 LLM 只在合法观察内决定措辞、沟通及候选行动，行动仍须由同一世界验证提交，不能读隐藏 oracle 或改写冻结规则。H 有目标、任务队列、私有采样/设备记录、注意力与可用窗口。策略版本在 pilot 后冻结，包括主动审查概率/触发、对求证的响应、失误生成与自我更正、短期不可用、截止前升级规则。策略只用 H 可见信息；不得读 oracle 或直接根据 Agent 的隐藏评语修正。H0 与 H1 除指定失误外尽量共享能力、时间、原件与资源条件；H1 可产生错误声明，但错误不是 H 的身份属性，纠正也非必然。若 H 当时证据不足且合理标不确定，不能事后贴 H1 标签。外生设备故障和合法修订在 H0 同样可发生。

H 的动作必须经过与 A 同一世界的授权和版本规则。记录 H 自发动作、应请求动作和未响应；允许先独立行动后通知 A。A 与 H 可相互发任务/消息，但消息本身不等同状态修订。H 的操作权限、实际可达能力和可见信息独立配置；例如有 QC 签字权仍可能因原始台账不在手边而无法签。PI/接任 H 如出场，计同一总人力且有限制视图，不作全知救援。

## 事件目录和条件

| 类 | 例子 | 世界与系统区别 | 典型竞态 |
|---|---|---|---|
| 人提交 | 样本标签、QC、配对、批准、撤销、交接 | 已录入声明可待核验，不自动为真 | A 读取 v1 后 H 提交 v2 |
| 仪器/worker | 预检、最终 QC、文件、失败、未知、重复回执 | 来源与文件 hash 独立于通知次序 | v2 先到、v1 后到；取消未确认 |
| 权限 | 到期、撤销、接任、限定共享 | 科学有效性与访问权分别判断 | 提交前撤权、旧 token |
| 资源 | 槽位抢占、维修、重试窗口 | 申请、确认、完成分状态 | 两控制者同时预约 |
| 数据/科学 | 合法后续修订、峰集更新、参考版本 | 原数据原件不改，解释依赖可变 | 候选验证后、发布前变化 |

触发谓词可为绝对逻辑时钟、读到指定对象、首次候选、首次受权请求或阶段截止，不得用最终评分/Agent 隐藏推理触发。发布后的新证据另起延续期，避免把已经合规的历史发布反写成当时违法；其后继续使用必须重新判断。冻结同一外生种子不意味着强制同一互动轨迹。

## 可解性判定

作者在运行前用**独立于待测 Agent**的可达性证明列出：双方当时/后续可见证据、必要动作主体、每条权限和能力窗口、设备/数据、事件最晚到达、动作耗时、截止、参考合法路径。可解：至少一条在预算与截止内符合科学断言的路径。条件可解：事件/伙伴响应分支决定，按预注册分支分层。不可解：无可用合法路径，例如最终 ATAC 从未到达且目标为联合结论；只能评正确等待/移交，不能算科学完成。设计时若发现 H 动作只是按 A 要求点按钮、A 无真实研究动作、或不可能在截止完成，任务须修订而非硬算失败。

## 故障与安全审计

重复事件按源 ID、hash、测量版本区分；同 key 异请求为冲突。外部未知先查原 job，不自动新建不可逆操作。old worker 回执必须可审计，不能覆盖新版本。公共世界提供同等授权、对象版本和基础原子提交；科学依赖、证据协调与是否限制旧结果由参赛系统决定，独立 oracle 评分。每条轨迹保存 shadow world truth、参赛系统 belief、verifier 输出及隐藏评分四个隔离视图；运行日志导出时红action/真值字段需防泄漏。
