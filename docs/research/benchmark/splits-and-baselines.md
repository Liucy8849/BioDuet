# 划分、强对照、消融与预算

## 公平赛道

**共享环境 Agent/Harness 赛道**：各组面对同一 action 并集、角色授权、状态视图、底模、技能、外生分布及总预算，公共 world 只保基础授权、对象版本、幂等与审计；科学依赖/门禁由被测方法自行做。**组件替换赛道**：在同一 C1 系统接口替换 C2 组件，固定 Agent 策略和其余组件以定位机制效应；若不能保证相同输入/输出语义，则只作配置比较。**原生整链赛道**：比较系统在共同可完成任务交集上的端到端表现，披露各系统原生能力、不同信息入口和无法执行的任务；不可把 adapter 为对照补上 C2 当公平性。三赛道不混成一张因果排名。

## 强基线

固定同底模且有相同领域工具的强 Agent；状态刷新与重新规划；乐观版本和依赖传播；条件重验；三者合理组合；常规工作流/一次性 Agent；C1+C2 候选。版本+依赖基线有其可实现的静态/显式依赖图，不故意不给证据。强 Agent 可以主动逐对象检查或保守全量重算，分别计正确性与成本。所有组看相同获授权原始证据、可用 actions/skills 并有相同顶层加子调用预算；通信、人侧时间、重试、计算都入账。若某种基线在 adapter 中获得自动科学失效传播，它已经拥有待比较能力，必须重分类。

## 消融

去持续状态访问、去前提证据更新、去依赖图利用、去被测组件专门验证门槛、被动伙伴对比主动伙伴。每项只改一个预注册机制，其余信息和基础安全保持。去门槛只在隔离评测输出槽运行，外部 oracle 仍评分，真实共享系统不可关闭基础授权/版本。被动伙伴与主动伙伴的信息/动作机会不同，只用于双控难度分析，不能归因 C2。模型/供应商更换是整配置比较，不伪称机制消融。

## 划分与重复

先按研究单元/供体、原始数据 accession、模拟事件模板家族、问题组合、原始文档和相似文本划开发、校准、隐藏测试；近重复 hash/相似性与人工审查双查。不能只随机拆 48 情境或拆细胞。开发可见任务及 checker 接口，正式留出 oracle、映射、种子和参考答案均不向 A/H 或调 prompt 者开放。H0/H1 使用可配对的外生条件估计条件效应，不能认为 24 模板或 48 条件就是最终 run 数。每模板跨数据/供体/事件/模拟人策略做预注册重复；以模板/数据来源为聚类单位给不确定区间，并报告最差模板、条件分层与所有失败。细胞数不当独立系统重复。

## 预算冻结程序

先 pilot 验证至少一条合法轨迹在各方法可达，测 H 自发动作、设备等待与计算成本；之后冻结统一模型、版本、提示、action/skill 并集、最大调用、尝试/重试、墙钟/计算/设备和人侧策略窗口。`20 模型调用/80 action/每 operation 3 attempt` 仅为旧草案的 pilot 候选，不能当正式阈值。不可观测 token/费用记 `unknown`，不可填 0。预算不足导致系统性不可解须修设计或单列资源失败，不能偏向某组。正式统计样本量依据 pilot 的簇内相关与目标效应/精度预注册，不以模板数量直接宣称功效。所有比较用相同外生种子配对，但互动轨迹可因双方行动不同而不同；不能人为强制同轨。
