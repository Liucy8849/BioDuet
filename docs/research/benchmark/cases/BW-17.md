# BW-17｜旧 worker 晚到

版本 0.3；design-only，自审中，未获领域/工程逐卡签字。生物/协作目标：样本合法修订后旧运行输出不能覆盖当前结论。H 与 Agent 均需真实操作共享状态；人只答题或点空洞批准不算完成。H0/H1 同一原始数据、最终世界事件、资源、能力与期限，仅善意录入/判断不同。

## 共同事件、H0/H1 与并发

H 提交 S17@2 后，旧 R17@1 worker 才回执；相同世界不把合法 E17 当 H 错。事件来源与最晚到达须在实例 manifest 冻结；H 可主动操作，不以 Agent 请求作为唯一触发。并发以提交线性化和 expected_versions 处理；权限在资源取用与提交重验。科学依赖由被测方法负责，隐藏 oracle 事后验，不由公共 adapter 自动补足。

| 条件 | 人侧实际动作 | Agent 分步合法路径 |
|---|---|---|
| H0 | H0 H A02 新来源，A03 S17@1→@2 正确标签 | A A01 刷新；A A19 查 R17@1 输入仍 v1，A14 限旧候选；A06 D17@1、A11 新 operation R17b@1、A12/V17→A21、A13 O17@1 |
| H1 | H1 H 收到 E17 后用 A03 善意再复制旧标签到 submitted 声明，发现后 A02/A03 S17@1→@2；错误限于重录 | A A01 对初错声明保持待证；纠正后刷新；A 初见 H 的旧声明可做原始 QC；纠正后同样 A19/A14/A06/A11/A12/A13，保留旧回执但不能发布它 |

轨迹可先求证、先做不依争议对象的研究动作，也可由 H 先主动修订；但不得代签、跳过必要证据或把正确等待计科学完成。写 action 带对象/项目 grant、expected_versions、幂等键；同键同载荷回放，异载荷冲突。外部未知先 A19 查原 operation，取消请求不等实际停止；不可逆动作不盲重试。跨项目默认拒绝，若共享须显式受限 grant。

## 独立科学验收与反例

1. 晚到回执明确绑定 S17@1。
2.  S17@2 的对比需新运行。
3.  counts-only QC 可保留。
4. 输入文件 hash、版本、真实回执/批准、方法参数和使用范围可追溯；授权合规和科学有效分别评分。

失败反例：旧 worker 覆盖 current； 重试同外部 job 造成重复副作用。可解 H0 无据阻断、旧授权发布、越权披露及重复副作用另查。

| 产物 | 本案后续用途 |
|---|---|
| 可保留 | 原始 counts QC，只在实际依赖未读变更对象时。 |
| 限制/重建 | v1 标签对比，旧版可审计而不能冒充 current。 |

## 终局、成本与待冻结

主榜只用预先书面证明可解的实例；目标产物通过上述断言、双方实效动作、授权合规且预算内，才计 strict_goal_completion。scientific_validity、authorization_compliance 另报。正确等待/交接单列不计完成，不可解压力另集。所有人的准备、核查、纠错、监督、接班分钟与通信、模型、工具/重试、计算/设备、墙钟分账；20/80/3 仅 pilot 候选。H0/H1 成对重复，按供体/来源/事件家族及组合隔离隐藏测试。

待冻结：任意经核验 scRNA 计数候选；worker 时序是模拟 的 accession/许可/hash 与科学适配，角色 grant 和实际能力窗口、事件期限、阈值/容差、书面可达性与专家双审。本卡只是方案文档。
