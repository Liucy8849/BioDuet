旧候选条件分支：只有实例 manifest 明列在纠正前由 A11 生成、标明旧输入版本的 R15pre@1（未发布）时，轨迹中的 A14 才限制该具体候选；未启用此分支则省略 A14，不能凭文字虚构旧结果。O@0 始终表示没有已发布结果。

## 独立科学验收

1. unknown 不是观测0。
2.  方法先于看结果固定。
3.  缺失机制限制解释范围。
4. 发布引用的文件 hash、对象/批准 revision、算法参数、来源/回执和使用范围可审计；进程成功不等科学有效。

失败反例：伪造0为观测； 擅自披露私有协变量。另查可解 H0 误阻断、越权披露及重复不可逆动作。科学未知只能评证据与谨慎范围，不由 oracle 硬判真值。

| 产物 | 变更后的用途 |
|---|---|
| 保留 | 原始 counts QC，须确实未依赖变更对象。 |
| 限制/重建 | 零值协变量调整；旧版本可供标明历史的审计，不可当当前结论。 |

## 终局、资源与待冻结

主榜实例需书面证明可解；只有目标产物通过上述断言、H/A 实效动作真实发生、权限合规且在预算内，才计 strict_goal_completion。scientific_validity 与 authorization_compliance 分列；正确等待/转交单列不计完成，不可解变体单独压力。记录全部人准备/核对/更正/监督/交接主动时间及通信、模型、工具、计算、设备、墙钟。20 模型调用/80 action/每 operation 3 attempt 只是 pilot 候选。H0/H1 成对重复，按原始来源/供体/事件家族/组合隔离正式隐藏测试。

待冻结：需有多供体公开 metadata 且许可允许所需协变量；敏感变量不能无授权使用 的具体 accession、许可、hash、供体/文库结构；科学阈值/数值容差、grant/能力窗口、事件上限、可达性书面推演和领域/工程逐卡审阅。本卡是方案文档，不可冒充已核验实例。
