# BioDuet project context

BioDuet evaluates life-science human–Agent collaboration when information and effective permissions are distributed between participants. It is a benchmark project, with its own source, documents, repository and server checkout.

A is the evaluated scientific Agent. H is an independently acting simulated scientific collaborator with role-specific evidence and actual actions. A worker executes jobs; it is not another simulated person. H0 has no designated injected error, though evidence may arrive late and online errors can occur. H1 contains a specified error. The benchmark must not secretly choose scientific actions for either participant.

The current research scope records two formal comparisons: common-environment capability and complete native-system performance. Internal mechanism/component-substitution studies are not an implementation objective. Native reasoning, memory and tool loops should remain native; a reference runner is infrastructure, not a replacement scientist.

The 24 cards address sample conditions, donor/aliquot lineage, time, QC, annotation, RNA/ATAC data, statistical designs and asynchronous scientific work. Wet-lab records can provide evidence; no completed live wet-lab instrument integration is claimed.

BW-01 concerns a condition-label problem. The Agent may see a change notice or discover a relevant analytical anomaly, seek evidence from H, then handle the scientific consequences. Existing analyses must actually exist before a task is described as old-result recovery. Label-independent QC should not be discarded merely because labels change.

The current code has engineering and controlled-computation history, but the autonomous BW-01 scientific loop, full 24-card evaluation and formal study are not complete. A completed process or synthetic test does not establish scientific validity.
